# Trusted contract ABIs

These complete ABI arrays are build inputs, never supplied by the engine or downloaded at runtime. `provenance.json` records the pinned origin, license, SHA-256 of the imported input, and SHA-256 of the canonical JSON bytes. For the two previously vendored Uniswap interfaces, the imported input is the retained ABI array, not the original artifact envelope. Other imported inputs are complete npm or compiler artifacts. Local contract artifacts use the compiler settings named in their provenance.

The router versions are intentionally separate: Uniswap SwapRouter02 wraps `exactInput` in deadline-bearing `multicall`; Pancake V3 SwapRouter includes the deadline inside its tuple. Neither is an interchangeable universal router. The pool interfaces, factory interfaces, QuoterV2 contracts and periphery-state interface also retain their own versions. `UniswapPeripheryState` describes the shared `factory()` and `WETH9()` getters, including those on the configured position manager.

## Generate and check

- `bun scripts/abi.ts` generates typed TS exports in `generated/abi/index.ts` and embedded Go mirrors in `services/quote-engine/internal/contractabi`.
- `bun scripts/abi.ts --check` verifies canonical hashes, the complete inventory, and generated bytes without writing.
- Outputs are ignored, not committed. Generation requires Bun and Go's `gofmt`; it needs no network or Solidity compiler. The canonical JSON, provenance and licenses stay tracked.
- `bun run generate` builds ABI and protobuf outputs. `bun run check` generates before compilation; `bun run check:generated` compares two independent clean generations. Run generation before direct Go builds or Bun source imports.
- Never edit generated mirrors. To update a protocol, review its pinned upstream artifact and license, replace its complete canonical ABI, update provenance hashes, regenerate, and run ABI/independent calldata tests. A checksum is change detection, not proof that a newly chosen upstream is trustworthy.

TS production ERC20 calls use viem's `erc20Abi`. Go uses the official OpenZeppelin IERC20 ABI here. Tests compare their shared selectors, return types and event indexing; this does not require handwritten duplicate ERC20 definitions.

`contracts/fixtures/executor-calldata.json` and its independent Cast/manual-layout generator remain independent encoding evidence. Sharing an ABI source must not turn expected calldata into output from the production encoder.
